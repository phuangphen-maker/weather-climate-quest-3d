# Weather & Climate Quest 3D

เกมผจญภัย 3D วิทยาศาสตร์ ม.1 สร้างด้วย Vite + Three.js + JavaScript ใช้ชุดคำถามที่ผู้ใช้ส่งให้ครบ 30 ข้อตามต้นฉบับใน `src/questions.json` ไม่มีการสร้างข้อสอบเพิ่มเติม

## เปิดเกม / Preview

ใช้ Node.js 24 (มี `.nvmrc`) และ npm:

```sh
cd /workspace/weather-climate-quest-3d
npm ci
npm run dev
```

เปิด Preview ของเครื่องมือพัฒนาที่พอร์ต **5173** หรือเปิด `http://localhost:5173` เมื่อรันบนเครื่องตนเอง เซิร์ฟเวอร์รับการเชื่อมต่อผ่าน `0.0.0.0` เพื่อรองรับเครื่องมือ Preview ของคลาวด์

ทดสอบไฟล์พร้อมเผยแพร่:

```sh
npm run build
npm run preview -- --port 4173
```

เปิด Preview พอร์ต **4173** ต้องเปิดผ่าน HTTP/HTTPS ไม่เปิด `dist/index.html` ด้วย `file://` โดยตรง ต้องใช้เบราว์เซอร์ที่รองรับ WebGL และ JavaScript

## วิธีเล่น

1. กรอกชื่อ–นามสกุล ชั้น และเลขที่ แล้วเริ่มเกม หรือเลือกเล่นต่อ
2. W/S หรือ ↑/↓ เดินหน้า/ถอยหลัง, A/D หรือ ←/→ เลี้ยว, Shift วิ่ง, Space กระโดด กล้องติดตามด้านหลังตัวละคร มือถือมีปุ่มกดค้างสำหรับเดิน เลี้ยว วิ่ง และกระโดด
3. เดินเข้าใกล้เครื่องหมาย **?** แล้วกด E หรือปุ่มสำรวจ ตอบได้ครั้งเดียวต่อข้อ ตอบถูกได้ 1 คะแนน ผิดได้ 0 คะแนน แสดงเฉลยและคำอธิบายทุกข้อ
4. ตอบครบ 5 จุดเพื่อไปด่านถัดไป หากปิดหน้าต่างผ่านด่าน ให้เปิด “ดูความคืบหน้า” แล้วกด “ไปด่านถัดไป”
5. เปิดห้องทดลองในแต่ละด่านเพื่อปรับตัวแปรและสังเกตแบบจำลอง ไม่มีคะแนนและไม่เพิ่มข้อสอบ
6. ตกบริเวณแอ่งน้ำหรือออกนอกเกาะ จะกลับจุดเริ่มต้นที่ปลอดภัยโดยไม่เสียคำตอบ
7. หน้าสรุปแสดงคะแนนแต่ละด่านและคะแนนเต็ม 30 ดาวน์โหลด CSV ได้ทั้งระหว่างเล่นและเมื่อจบ เล่นครบแล้วเริ่มใหม่จากด่าน 1 ได้ โดยจะยืนยันก่อนล้างคำตอบ

เสียงสังเคราะห์จาก Web Audio ทำงานหลังผู้เล่นโต้ตอบ สามารถปิดเสียงได้ ไม่ต้องโหลดไฟล์เสียงหรือฟอนต์จากภายนอก

แต่ละด่านมีฉากและวัตถุ 3D ประกอบ ห้องทดลองเป็นแบบจำลองอย่างง่ายเพื่อเรียนรู้ ไม่ใช่เครื่องมือพยากรณ์จริง กราฟความดันใช้ P ≈ 1013.25 exp(−h/8400) hPa ส่วนค่าความชื้นเป็นแบบจำลองเชิงสาธิต ไม่ใช้แทนข้อมูลวัดจริง

## การบันทึกและข้อมูลนักเรียน

ใช้ `localStorage` คีย์ `weather-quest-v1` เก็บผู้เล่นล่าสุดและคำตอบอัตโนมัติในเบราว์เซอร์/อุปกรณ์และโดเมนนั้น ไม่มี backend ไม่มีบัญชีผู้ใช้จริง และไม่ส่งข้อมูลนักเรียนไปยังเซิร์ฟเวอร์ การล้างข้อมูลเว็บ เปลี่ยนอุปกรณ์ เปลี่ยนโดเมน หรือเริ่มใหม่ทำให้ไม่พบข้อมูลเดิม ควรดาวน์โหลด CSV ก่อนเริ่มใหม่หรือเปลี่ยนผู้เล่น CSV เป็น UTF-8 พร้อม BOM สำหรับภาษาไทยใน Excel มีชื่อ ชั้น เลขที่ คำตอบ เฉลย คำอธิบาย และคะแนนทุกข้อ

ใน iframe บางเบราว์เซอร์อาจจำกัด localStorage หรือดาวน์โหลด ให้เปิด URL เกมโดยตรงเพื่อบันทึกและดาวน์โหลด CSV

## เผยแพร่ Netlify

เตรียม `dist/` ด้วย `npm run build` แล้วเลือกได้สองวิธี:

- อัปโหลด **โฟลเดอร์ dist ทั้งโฟลเดอร์** ผ่าน Netlify Drop (หรือแตก `weather-climate-quest-3d-dist.zip` ก่อนอัปโหลด) ให้ `index.html` อยู่ที่ root ของเว็บไซต์
- เชื่อม repository บน Netlify: Build command `npm run build`, Publish directory `dist`, Node.js 24 มี `netlify.toml` เตรียมไว้แล้ว

ไม่ต้องใช้ API key หรือ environment variable สำหรับเกมนี้ ไฟล์ build ใช้ path แบบ relative รองรับการวางใน subdirectory

## ฝังใน Google Sites

Google Sites ไม่สามารถอัปโหลดโฟลเดอร์ Vite/dist เพื่อรันเกมโดยตรง ให้เผยแพร่บน Netlify ก่อน แล้วใช้ **แทรก → ฝัง → URL** ใส่ URL HTTPS ของเกม หรือใช้โค้ด:

```html
<iframe
  src="https://YOUR-SITE.netlify.app/"
  title="Weather & Climate Quest 3D"
  width="100%"
  height="850"
  style="border:0"
  allow="fullscreen"
  allowfullscreen
>
</iframe>
```

แทนที่ URL ด้วยเว็บไซต์จริง ปรับความสูงของกรอบให้เห็นปุ่มมือถือครบ และเพิ่มลิงก์ “เปิดเกมเต็มหน้าจอ” ไปยัง URL โดยตรงสำหรับผู้เล่นที่ดาวน์โหลด CSV ในกรอบไม่ได้

## ทดสอบเบราว์เซอร์

```sh
# ถ้าไม่มี Chromium ในระบบ
npx playwright install chromium
npm test -- --workers=1
```

การทดสอบเลือก `/usr/bin/chromium` หากมี หรือใช้เบราว์เซอร์ Playwright ที่ติดตั้ง สามารถกำหนด `CHROMIUM_PATH` เองได้ ชุดทดสอบเปิด dev server ให้อัตโนมัติ ตรวจการเดินถึงคำถาม ตอบถูก/ผิด การไม่ให้ตอบซ้ำ เล่นต่อ CSV ห้องทดลองทั้ง 6 ด่าน เปลี่ยนด่าน จบเกม เริ่มใหม่ และหน้าจอมือถือ ใช้ข้อมูลเริ่มต้นจำลองสำหรับบางสถานการณ์เพื่อเข้าถึงแต่ละด่านโดยตรง ไม่ได้หมายถึงทดสอบการเดินทุกเส้นทางบนมือถือจริง

โครงสร้างหลัก: `src/main.js` ระบบเกมและฉาก, `src/style.css` หน้าจอ, `src/questions.json` ชุดข้อสอบ, `tests/game.spec.js` การทดสอบ, `vite.config.js` การ build, `netlify.toml` การเผยแพร่

## ดาวน์โหลด ZIP จาก GitHub
